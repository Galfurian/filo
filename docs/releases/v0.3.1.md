Fixes for eight problems that property-based tests found in how filo reads what other processes write to it. If you run filo, upgrade: one of them let a single frame sent to a listener end that listener.

**Fixes**

- **A deeply nested JSON frame ended the listener.** A document nested tens of thousands of levels deep (a 100 KB frame is enough) raised `RecursionError` in the reader of a socket frame and of a metadata file, and nothing caught it. Any process of yours could stop a listener that way (the sockets and files are private to your user, so no one else could). It is now a protocol error, like any other bad frame.
- **`Infinity` in a number field** raised an exception that the callers did not catch. It is now an ordinary bad value.
- **A name could be `.` or `..`**, which as a directory under `spool/` and `inbox/` is the directory above it. Both are refused now.
- **A message whose `origin` held a NUL character was lost** instead of delivered. An origin that cannot be checked now counts as coming from another directory.
- **The reply command put the sender in unquoted**, so a sender with a space or a semicolon in its name split into several words. It is quoted now; valid names are written as before.
- **A message that contained `{scope}`, `{session}` or `{message}` was altered on its way to a client run by an adapter**, which replaced the placeholders one after the other. They are replaced in a single pass, and the message arrives as it was written.
- **A shortened event of an empty body was marked `truncated`**, with nothing cut.
- **`--scope ~nobody`**, for a user that does not exist, ended with a traceback. It is a keyword now, like any other word.

**Changes in behaviour**

`.` and `..` are no longer valid names (`filo join --as ..` is an error). Nothing else a user does changes.

**Tests**

`tests/test_properties.py` states what must hold for any input, with Hypothesis (a dev tool only: filo still has no dependency). Each of the eight is now an `@example` of the test that found it. `HYPOTHESIS_PROFILE=explore` searches harder; `CONTRIBUTING.md` says how.

**Upgrade**

`filo upgrade`, or the one-line install again. A session that was started before the upgrade runs the old version until it is restarted.
